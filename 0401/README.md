# 📑 React 프로그래밍 학습 노트 (04)

## 1. 컴포넌트(Component)의 이해
리액트 UI를 구성하는 가장 기본적이고 핵심적인 단위입니다.

* **정의:** 입력(`props`)을 받아 화면에 표시할 엘리먼트(`Element`)를 반환하는 **재사용 가능한 독립 모듈**입니다.
* **특징:** * 자바스크립트 함수와 유사하게 동작합니다.
    * 복잡한 UI를 **레고 블록**처럼 작은 단위로 쪼개어 조립하고 관리할 수 있게 해줍니다.

---

## 2. Props와 데이터 전달
컴포넌트 간에 데이터를 주고받는 핵심 수단입니다.

* **Props:** 부모 컴포넌트가 자식 컴포넌트에게 전달하는 **읽기 전용 입력값**입니다.
* **실습 요약:** * `Comment` 컴포넌트를 설계하여 이름(`name`)과 내용(`comment`)을 전달받음.
    * 전달받은 데이터를 컴포넌트 내부에서 동적으로 렌더링하여 화면에 표시함.

---

## 3. 컴포넌트 구성 및 반복 렌더링
데이터 배열을 효율적으로 화면에 출력하는 방법입니다.

* **데이터 분리:** `comments` 배열 객체를 생성하여 데이터와 UI 로직을 분리합니다.
* **`map()` 활용:** 자바스크립트의 `map()` 함수를 사용하여 배열 내의 각 데이터를 바탕으로 다수의 `Comment` 컴포넌트를 **동적으로 자동 생성**합니다.

---

## 4. 과제 및 주요 발표 주제

| 주제 | 핵심 체크포인트 |
| :--- | :--- |
| **Pure vs Impure Function** | 입력값이 같으면 결과도 항상 같은지(부작용 여부)에 따른 구분 |
| **Arrow & Lambda Function** | `=>`를 이용한 간결한 함수 표현식 및 최신 JS 문법 숙지 |
| **`map()` 함수의 활용** | 배열 데이터를 반복적인 컴포넌트 리스트로 변환하는 필수 기법 |
